# 🚘 2주차 자동차 경주

## 기능 요구사항 요약

- **입력**
  - 자동차 이름과 시도할 횟수를 입력받는다.
  - 자동차 이름은 쉼표(`,`)를 기준으로 구분하며 각 이름은 5자 이하만 가능하다.
  - 사용자가 잘못된 값을 입력한 경우, `"[ERROR]"`로 시작하는 메시지와 함께 `Error`를 발생시키고 프로그램을 종료한다.
- **게임 진행**
  - 각 자동차는 입력받은 시도 횟수 동안 전진하거나 멈출 수 있다.
  - **전진 조건:** 0에서 9 사이의 무작위 값을 구해 해당 값이 4 이상일 경우 전진한다.
  - 한 턴이 끝날 때마다 현재 경주 상황을 출력한다.
- **게임 종료**
  - 모든 시도가 완료되면 최종 우승자를 출력한다.
  - 우승자가 여러 명일 경우 쉼표(`,`)로 구분하여 출력한다.

## 프로그램 흐름

1. 경주할 자동차 이름을 입력받는다.
   - 입력은 쉼표(`,`) 기준으로 구분한다.
   - 입력된 이름이 올바른지 확인한다.
     - 이름이 비어 있지 않은지
     - 이름이 5자를 넘지 않는지
     - 이름에 공백이 들어가지 않았는지
2. 시도할 횟수를 입력받는다.
   - 입력된 값이 양의 정수인지 확인한다.
3. 입력값이 모두 올바르면 게임을 시작한다.
   - 게임은 사용자가 입력한 라운드 수만큼 진행된다.
   - 각 자동차는 매 라운드마다 0부터 9 사이의 랜덤 숫자를 하나 뽑는다.
   - 숫자가 4 이상이면 자동차가 한 칸 전진한다.
   - 모든 자동차의 이동이 끝나면 현재까지의 경주 결과를 출력한다.
4. 모든 라운드가 끝나면 우승자를 출력한다.
   - 가장 멀리 이동한 자동차가 우승자가 된다.
   - 우승자가 여러 명이면 쉼표(`,`)로 구분해서 함께 출력한다.

## 구현해야할 기능 목록

### Car

- [x] `move()` : 자동차의 위치를 1 증가 시키는 기능
- [x] `getPosition()` : 자동차의 현재 위치를 반환하는 기능

### Validator

- [x] `validateCarNames(names)` : 자동차 이름이 올바르게 입력되었는지 검증하는 기능
- [x] `isEmpty(names)` : 자동차 이름 중 비어 있는 값이 하나라도 있는지 확인하는 기능 (구분자 앞뒤가 비어 있는 경우 포함)
- [x] `isInvalidLength(names)` : 자동차 이름 중 5자를 초과한 값이 있는지 확인하는 기능
- [x] `hasWhitespace(names)` : 자동차 이름 중 공백 문자가 포함된 값이 있는지 확인하는 기능
- [x] `validateRoundCount(count)` : 입력된 라운드 수가 올바른 값인지 검증하는 기능
- [x] `isNotPositiveInteger(count)` : 1 이상의 정수가 아닌지 확인하는 기능

### GameView

- [x] `inputCarNames()` : 경주할 자동차 이름을 입력 받는 기능
- [x] `inputRoundCount()` : 게임을 진행할 라운드 수를 입력 받는 기능
- [ ] `printProgress()` : 각 라운드가 끝날 때마다 자동차들의 현재 위치를 출력하는 기능
- [ ] `printWinners()` : 최종 우승자를 출력하는 기능

### GameService

- [x] `setCars()` : 검증된 이름으로 자동차 객체들을 생성하는 기능
- [x] `setRoundCount()` : 진행할 라운드 수를 저장하는 기능
- [ ] `playRound()` : 한 라운드를 진행하는 기능
  - 각 자동차가 0~9 사이의 랜덤 값을 뽑는다.
  - 값이 4 이상이면 한 칸 전진시킨다.
- [x] `isFinished()` : 모든 라운드가 종료되었는지 확인하는 기능
- [ ] `getWinners()` : 가장 멀리 이동한 자동차 이름을 반환하는 기능

### GameManager

- [x] `setup()` : 게임 시작 전 자동차 이름과 라운드 수를 입력 받아 시스템에서 이용 가능하도록 구성하는 기능
- [ ] `play()` : 입력받은 라운드 수 만큼 경주를 진행하는 기능
- [ ] `showResult()` : 모든 라운드가 끝나고 결과를 보여주는 기능
- [ ] `start()` : 게임 준비 -> 게임 진행 -> 게임 결과 순으로 게임 전체를 실행하는 기능
